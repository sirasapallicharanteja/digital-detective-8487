## 2. Task 1.1 – Understanding IPOS

IPOS stands for:

- **Input:** The data or instructions given to a computer.
- **Processing:** The computer works on the given input.
- **Output:** The result produced by the computer.
- **Storage:** The process of saving information for future use.

### Real-Life Example: Typing and Saving a Document

When I type and save a document on my computer, the following activities take place:

**1. Input**
- I enter text using the keyboard.
- The keyboard sends the information to the computer.
- Hardware used: Keyboard.

**2. Processing**
- The CPU processes the instructions and handles the data.
- RAM temporarily holds the information while the computer is working.
- Hardware used: CPU and RAM.

**3. Output**
- The computer displays the typed text on the screen.
- I can see the document and make changes.
- Hardware used: Display.

**4. Storage**
- When I save the document, the computer stores it for future access.
- Hardware used: SSD.

### What I Understood

The four stages of IPOS work together to make a computer useful. Every time I perform an activity such as typing and saving a document, the computer receives input, processes it, displays the result and stores the information.

## 3. Task 1.2 – Identifying Hardware and Software

### A. Hardware

Hardware refers to the physical components of a computer that we can see and touch.

Examples:

**1. Keyboard**
- Used to enter text, numbers and commands.

**2. Trackpad**
- Used to move the pointer and interact with the computer.

**3. Display**
- Shows text, images, videos and other information.

**4. SSD (Solid State Drive)**
- Used to store files, applications and other data.

### B. Software

Software refers to programs and instructions that tell a computer what to do.

Examples:

**1. macOS**
- Category: Operating System.
- Purpose: Manages computer hardware, memory, files and applications.

**2. Visual Studio Code**
- Category: Application Software.
- Purpose: Used to write, edit and manage programming code.

**3. Google Chrome**
- Category: Application Software.
- Purpose: Used to browse websites and access information on the internet.

**4. Activity Monitor**
- Category: Utility Software.
- Purpose: Helps monitor CPU, memory and other system activities.

### What I Understood

Hardware and software depend on each other. Hardware provides the physical components, while software provides the instructions. Both work together to perform different computer operations.

## 4. Task 1.3 – Computer-Based Systems in Everyday Life

Computer-based systems use computers or electronic controllers to perform specific tasks.

### A. ATM (Automated Teller Machine)

**Purpose:** An ATM allows customers to perform banking activities such as withdrawing money.

- Input: Bank card and PIN.
- Processing: The system verifies the information and processes the transaction.
- Output: Cash and transaction information.

### B. Smart TV

**Purpose:** A smart TV is used to watch television programmes and online content.

- Input: Commands from the remote control.
- Processing: The TV processes the selected channel or application.
- Output: Video and audio.

### C. Traffic Signal

**Purpose:** Traffic signals control the movement of vehicles and pedestrians at road junctions.

- Input: Timer or vehicle sensor information.
- Processing: The controller determines which signal should be active.
- Output: Red, yellow and green traffic lights.

### What I Understood

Computer-based systems are used in many everyday activities. They accept input, process information and produce output to perform their specific functions.
