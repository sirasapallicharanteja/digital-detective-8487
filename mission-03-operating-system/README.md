# Mission 3 — Understand the Operating System

## 1. Task / objective
Explore macOS, running processes, storage, paths and file permissions.

## 2. Work completed
- Explored operating-system information.
- Checked the active account and available storage.
- Observed running processes and their PIDs.
- Practised absolute and relative paths.
- Studied file permissions.
- Identified six operating-system responsibilities.

## 3. Commands / tools used
- `sw_vers` — displays macOS version.
- `whoami` — displays current account.
- `df -h` — displays storage information.
- `top` — displays system activity.
- `ps aux` — lists processes.
- `pwd` — displays current directory.
- `cd` — changes directory.
- `ls -l` — displays detailed file information.

## 4. My understanding
I learned that an operating system manages hardware, software, memory, processes, files and permissions. I also understood how processes run and how file permissions control access.

## 5. Difficulties faced

## 6. How I resolved them
