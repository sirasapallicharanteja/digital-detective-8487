# The Digital Detective

## About This Project

This repository contains my work for the Digital Detective Diwali Independent Learning Assignment.

The purpose of this assignment is to understand how computers work, explore the operating system, practise Terminal commands, learn Python basics, understand number systems and explore Git, GitHub and computer networks.

## Running the Number Converter

After completing Mission 5, open Terminal inside the project folder and execute:

```bash
cd mission-05-numbers-data
python3 number_converter.py
```
