# Mission 2 — Become Comfortable with the Terminal

## 1. Mission Objective

The objective of this mission is to become comfortable using Terminal commands to navigate directories, manage files, understand command options and pipes, and learn about package managers.

## 2. Tasks Completed

### Task 2.1 — Basic Terminal Operations

- Practised checking the current directory using `pwd`.
- Listed files and folders using `ls`.
- Viewed detailed file information using `ls -l`.
- Navigated between directories using `cd`.
- Created a directory using `mkdir`.
- Created files using `touch`.
- Copied files using `cp`.
- Renamed files using `mv`.
- Displayed file contents using `cat`.

### Task 2.2 — File Management

- Created a text file.
- Added text using `>`.
- Appended text using `>>`.
- Displayed file contents using `cat`.
- Created a backup using `cp`.
- Renamed the backup using `mv`.

### Task 2.3 — Flags and Pipes

- Practised `ls`, `ls -l`, `ls -a` and `ls -lah`.
- Used a pipe to send command output to another command.
- Practised `head -n 5`.

### Task 2.4 — Package Managers

- Learned what a package manager is.
- Learned about Homebrew.
- Checked whether Homebrew was available using `brew --version`.
- If installed, listed Homebrew-managed packages using `brew list`.
- Did not install or uninstall any software.

## 5. Difficulties Faced

- I found it difficult to understand the difference between `>` and `>>` when writing    and appending text to files.
- Understanding how a pipe (`|`) passes the output of one command to another command was also challenging.
- I needed to understand the purpose of a package manager and how Homebrew works on macOS. 

## 6. How I Resolved Them

I resolved these difficulties by practising the commands in the VS Code Terminal and observing their outputs.

- To understand `>` and `>>`, I practised writing and appending text to files and checked the results using the `cat` command.
- To understand pipes, I practised using `ls -lah | head -n 5` and observed how the output of the first command was passed to the second command.
- To understand package managers, I learned about their purpose, explored Homebrew and checked its availability using `brew --version`.

Through these activities, I improved my understanding of Terminal commands and became more comfortable using the command line.
